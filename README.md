# 🍔 Де поїсти ФІТ? — Студентський агрегатор їжі

Вебзастосунок для студентів **КНУ імені Тараса Шевченка (ФІТ)**, який допомагає знайти найкращі заклади харчування навколо корпусу на вулиці Богдана Гаврилишина та біля метро Політехнічний інститут.

## ✨ Основні можливості (MVP)
- **Каталог закладів:** Реальні місця навколо ФІТ із актуальними рейтингами та адресами.
- **Розумна фільтрація:** Пошук за категоріями (Шаурма, Кава, Українська кухня, Японська кухня тощо).
- **Живий пошук:** Миттєвий пошук за назвою закладу або тегами.
- **Система акаунтів:** - Реєстрація та вхід.
  - Можливість завантажити власну аватарку або обрати пресет.
  - Редагування профілю.
- **Інтерактив:**
  - Додавання закладів у "Улюблені".
  - Можливість залишати власні відгуки (доступно для авторизованих користувачів).
- **Зворотний зв'язок:** Швидкий перехід у Telegram для підтримки або пропозиції нових закладів.

## 🛠 Технологічний стек
- **Frontend:** React + TypeScript
- **Стилізація:** Tailwind CSS
- **Іконки:** Lucide React
- **Анімації:** Framer Motion
